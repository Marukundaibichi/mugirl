# 巨企 UI 验收修订：2026-09-16

按玩家验收意见移除面板左上短线、按钮悬停下划线及弹窗角标。黑色主体、少量白色强调、几何背景、按钮反馈、平滑滚动与开关/切页动画继续使用。

## 本轮界面

- 贸易页参考玩家的 `MRK_ALG_UniversalTradeHub` 模块，使用图标目录、分类、搜索、价格排序、展柜/清单切换与独立结算区；窄窗口上下排列，目录与结算区可滚动。商品切换只对详情区做淡出淡入，快速比较时保留最后选择。
- 订购页同时展示单价、交期、材料、品质、数量及总价。现货与订购报价复用真实交易方法。旧特供现货隐藏并拒绝成交；旧稀有现货按现行价格下限成交，已付款订单保留原条款。
- 人员页使用名单与单人档案；年龄、健康、报价独立展示，完整技能、热情、特性、身体能力、疼痛、分部位健康记录、服装品质/耐久分别排版。窄窗口用选人菜单，成交按钮固定在底部。
- 主页面文案改为简短的部门口吻。合同的利息、退款、不可逆转让及交易后果保留在报价、提示和确认窗；故事对白保留叙事长度。

## 后续红字修复

上述记录对应界面验收版本。后续玩家日志确认两项遗漏：订单预览会尝试销毁原版不可销毁的主脑节点；旧测试程序集的两个 `GameComponent` 驱动曾被游戏自动写入玩家存档，卸掉测试类型后造成读档红字。先前使用独立 savedata 的测试方式不能证明测试程序集未被其他游戏进程加载。

本次已排除受保护商品，并在内存读档阶段精确移除这两个过期测试组件。验证驱动改为普通类，启动器也改为独立程序集和独立游戏目录，不再临时覆盖正式 DLL。玩家原始存档不作直接编辑。修复与验证记录见 `corporate-ui-errors-2026-09-16.md`；以上 DLL 指纹保留为历史记录。
