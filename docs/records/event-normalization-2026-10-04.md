# 联络员入口、未招募产奶与民间事件整合（2026-10-04）

## 范围与基线

按用户要求补齐关闭开局坠机时的巨企联系路径，修复未招募对象的喝奶、榨乳，整合民间事件并删除野人闯入玩法。用户明确同意为既有随机坠舱救援、流浪者申请加入任务补自然随机入口。

修改前已记录工作区和 DLL 哈希，静态基线通过。唯一预先存在的未跟踪文件 `1.6/Assemblies/NewbornBackstoryProbe.dll` 保留未改；它是需要独立开关才能运行的新生儿测试探针，不是玩法组件。本轮证据与原 DLL 备份位于 `TMP/EventNormalization-20261004/`。

## 行为变更

- 关闭开局剧情且尚未发生开局坠舱、运货员时，联络员在有玩家殖民地后等待约两天独立拜访。任务、信件、交谈与完成记录使用“主动拓展客户”的专用中英文文本，不提未发生的运货员经历。开户、礼物与服务权限不变。
- 开启开局剧情时按“坠舱 → 运货员 → 处理/离图 → 120000 ± 9000 tick → 联络员”的顺序。未解决运货员不启动等待；战斗仍在进行时延后来访。尚未开始剧情的中途加装旧档也遵循开关与顺序。
- 独立拜访前重新打开开局剧情，会取消独立倒计时；代表已经入场则保留路线与重访。独立路线、倒计时和完成状态均保存，读档不重复送礼。
- `CompMooMilkable.Active` 不再继承“派系非空”的身体资源基类门槛。无派系成年雪牛娘正常积奶，奶量足够时可以手动榨乳或喝奶。年龄、性别、设备接管、产量、消耗和自动工作扫描范围不变。
- 民间随机定义归并到 `Incidents_Mugirl.xml`。将已移除野人事件的基础权重 1.0 分为随机救援 0.6 与申请加入 0.4；其余三项事件权重不变。开局双人坠舱仍由剧情组件调度。
- 流浪者任务补写 RimWorld 1.6 的 `GeneratePawn_NewTemp(Map)`，避免实际任务入口落回原版人类生成器；信件明确接受/拒绝与一天时限，慈善提示放回正文，并清除误覆盖原版流浪者信件的无前缀翻译键。
- 随机救援共用开局的两天疲惫 Hediff，保证安全倒地。此前仅设置 `forceDowned`，不能在未失能时强制倒地，实测可能反复重试后生成空任务。
- 救援和申请加入在任务登记前注册世界人物时，显式保留无派系状态。原版 `Pawn.Notify_PassedToWorld` 会给自由世界人物随机分配派系，曾使救援生成后的校验失败，也可能把申请加入者划给巨企；普通巨企人员离图登记不启用此保留选项。
- 五处民间人物生成共用成年、女性、无派系、可招募约束；事件各自保留特殊服装、伤势与去留。中英文任务名区分开局与随机救援，并修正开局信件“一舱两人”与实际状态描述。
- 野人闯入旧 Worker 删除；旧 Def 仅留在兼容目录，隐藏、零权重且拒绝强制执行，用于读取旧队列和历史引用。旧野人 PawnKind 与已生成角色保留。

## 验证方法

构建与检查采用现有 Steam 安装。运行期探针 `docs/tools/EventNormalizationRuntimeProbe.cs` 独立编译，只有显式 `-mugirlEventProbe` 且配置目录在本模组 `TMP` 下才启用；不编入正式 DLL。验证使用独立配置和存档，不复制游戏启动程序或资源树。

探针检查真实任务 Worker、代表生成和对白、两个阶段的保存/读档、真实右键菜单及喝奶/榨乳 Job；不是只直接调用奶量结算。随机选择权重通过运行期 Def 验证，不把开发测试的强制触发当成长期发生频率统计。

本轮初次受限启动无法连接 Steam、因而缺少 Harmony/HAR；改为允许 Steam 通信的同一安装后依赖正常加载。一次隐藏窗口快速测试未进入有效地图，保留对应日志，不计为通过。早期夹具曾对已放行运货员再次选战斗、提前生成无任务引用的世界人物后长时间等待，已改为独立分支和即时生成入场。
