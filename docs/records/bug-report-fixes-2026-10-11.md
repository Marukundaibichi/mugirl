# 2026-10-11 玩家报告核查与修复

## 范围与已知条件

报告来自其他玩家，未提供完整模组列表。“所有近战武器不能订购”未在报告者环境复现；代码与合成组件可以确认旧版会因 `PostDraw` 等展示回调误拒绝供货。原版匕首本身可订购。其余报告分别涉及加工报酬/提示设计、堆叠物统一 2,500 上限及 Job 中文漏项。

修改前记录工作区状态、原差异与 DLL 备份，保留已有事件、产奶、轮盘及文档改动，包括原有 `NewbornBackstoryProbe.dll`。不恢复用户删除的内容，不修改正常游戏配置和存档。

## 实现

- `CorporatePricingCompatibility` 按覆写的原版回调职责区分显示与潜在行为；保留未知生命周期、交互、产出及 tick 行为的限制。开发模式日志包含 Def、组件及方法。没有对近战武器整体开白名单，也不能用静态回调分类保证任意第三方方法体都无副作用。
- 新生成的加工单报酬为 `max(150, 普通产品总市值 × 原有25%–40%比例, ceil(每批实际工作量 × 批次 × 20 / 2500))`。配方一次产出多份不重复累计工作量，材料修正由游戏配方 API 解析。已有可接或已签合同报酬不重算。
- 加工条款明确巨企提供原料、保证金完成后全退、净加工费与总回款，仍由玩家安排账单。交货优先最低合格品质；需要良好及以上成品时确认，默认业务调用只消耗普通或无品质货物。高品质不追加报酬。
- 单笔限购：不可堆叠物 10；可堆叠物标准单价达到 1,000 白银时 10，否则 2,500。标准单价使用当前规格、折扣前未加急的报价及兑现价值底价；客户折扣和加急不改变档位。界面与提交后端共享计算，超额先拒绝再扣款，已付款订单按原合同交付。
- 补齐“正在被挤奶。”、配合喂奶及两种骑枪冲锋的 Job 中文与中英对应。静态检查从 JobDef 源定义反查中文，不再只依赖英文键集合。

配置项：`CorporateTradeSettings.highValueOrderThreshold = 1000`、`CorporateQuestConfigDef.processingFeePerWorkHour = 20`。当前为首轮平衡参数；标准工作量不是殖民者实际耗时，也不保证消耗自有库存时的机会成本。
