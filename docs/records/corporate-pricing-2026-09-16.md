# 巨企采购调价：2026-09-16

本轮提高稀有订单的资金门槛与备货期，尤其提高原版商人不供应的物资。每周现货仍是有限库存；特供物资必须走订单。

| 采购档位 | 单价 | 备货 |
| --- | --- | --- |
| 普通 | 实际市场价值 ×2.2 | 3–5 日 |
| 稀有 | 实际市场价值 ×6 | 12–20 日 |
| 执政官级 | 实际市场价值 ×10 | 20–35 日 |
| 特供 | 实际市场价值 ×20，且每件不少于 20,000 白银 | 30–60 日 |

使用实际物品的市场价值，因此材料、品质与物品状态仍参与报价；总价最后向上取整。多个档位同时适用时，价格倍数与备货上下限分别取最高值。

稀有判据为太空时代以上、基础市值不低于 500，或配置显式列为稀有。目前额外列入高科零部件与超织物：它们在当前运行时 Def 中的技术等级均为 `Undefined`，不能只靠技术等级识别。

特供包括 `Tradeability.Sellable` 物品，以及配置中的灵能神经塑形器、碎片、亡魂脊柱、死眠炮弹。后三类和神经塑形器虽然允许双向交易，原版商人的供应生成器并不生产它们。对应 DLC 未启用时，`MayRequire` 会移除列表项。生物铁虽然在多处收购列表中，但原版稀有商船和萨满商人有明确供货，因此没有归入特供。

当前 Def 基础价值推算的正常状态单件报价示例：治疗机械液 26,000、复活机械液 34,000、研究技术核心 20,000、AI 人格核心 80,000、灵能神经塑形器 52,000 白银；碎片、亡魂脊柱与死眠炮弹适用 20,000 下限。实际游戏成交仍以创建后的物品报价为准。

每周库存的常备与补充候选均排除特供。稀有现货采用对应采购档位的单价下限，普通现货仍保留现货价格；`StockUnitPrice` 使旧存档里的稀有现货也使用现行下限，并保留高于下限的旧报价。界面与实际扣款共用该方法。`BuyStock` 同时拒绝旧存档中残留的特供现货条目，避免按旧的低价与即时交付绕过采购档位。已签订单保存的 `paid`、`createdTick`、`readyTick` 不会重算；普通物品可订购条件与特殊生成对象排除条件未放宽。

## 数据证据与验证

- `rimsearcher get <defName> --type ThingDef`：核对实际合并 Def 的交易方向、技术等级、物品类别和市场价值。治疗机械液、复活机械液、研究技术核心、AI 人格核心均为 `Sellable`；技能训练器为 `All`。
- `rimsearcher list --type TraderKindDef` 与各商人的 `stockGenerators`：核对神经塑形器、碎片、亡魂脊柱、死眠炮弹的买入生成器和普通供应排除；避免把“商人会收购”误判为“商人会出售”。
- `CorporatePricingChecks.RunQuotes`：在真实游戏中检查各档实例报价、备货、配置加载、重叠档位、高价下限与特殊对象排除。
- `CorporatePricingChecks.RunContract`：在隔离地图实际签订治疗机械液订单，核对支付、具体到货日期、调价不改旧约、原金额退款，以及旧现货条目不能绕过特供规则。地图退款通过递归统计地图与空投容器的实物白银检查，不假定退款会立即进入贸易信标。

本轮 `CorporateValidation-ReviewRevision2` 在实际 RimWorld 1.6.4871 中通过 60 项报价、库存、下单和退款断言，无运行错误。含全部五个 DLC、Harmony、HAR 与本模组；使用一次性测试殖民地，不读取玩家正式存档。实际证据见 `DevData/Evidence/CorporateValidation-ReviewRevision2-Evidence/visual-result.txt`，界面与验证范围见 `corporate-ui-2026-09-16.md`。
