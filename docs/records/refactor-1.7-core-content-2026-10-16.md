## 结构与行为边界

- 设置使用规范标签和独立 settingsSchema；窗口保持原控件顺序、文案与延后刷新时点。外观刷新和轮盘开发动作通过注册入口接入，Core 不直接引用功能实现。
- 生命周期保留原 Storyline.FinalizeInit 的瞬态重置位置与顺序，另提供 BeforeLoad/BeforeNewGame。实际有效的渲染待办清除保留；已空的 Def 缓存重置移除。Corporate 构造中的债务覆盖重置尚不能移动而保持原行为，保留明确例外。
- 两个旧 Game.ExposeSmallComponents 迁移补丁移入 SaveUpgrade。退役野人事件仍保持原 Def、文字和拒绝执行行为，只把 worker 移到升级层。旧计划中删事件、改角条件、改文案等改变不执行。
- 删除已核实零调用的预览/世界人物辅助方法、ThingDef 身份重载和无门控日志工厂重载。Lactation Expansion 的常量/开关转发类合并到现有 ModCompat；补丁顺序不变。
- 1911 个内容与素材文件对 post-R2 基线核对，唯一变化是 RetiredEvents.xml 的 workerClass；语言、数值、素材未改。

## 一次性升级基础设施

DOM 新增重挂节点原语：先校验最终父链，再按父节点成组脱离和挂接；保持 XmlElement 身份，循环、重复写入、移入已删目标或 game 子树外均拒绝。对象移动不登记为删除，不破坏引用身份。

完整旧 Def/组件关系由语料生成并由 Core 一次注册，避免单个模块覆盖其他组件的关系。共享旧标签只有被同一个步骤消费时才可重复声明，不能掩盖相互冲突的改名或删除。

加载 ID 仅在 Thing.id 和真实 Scribe 引用登记边界转换；普通玩家字符串即使与旧 ID 完全相同也保留。Reference 字典只在实际读取器和键值位置都已证明时成对删除，未知深层值生命周期拒绝盖成功戳。Verb 自身 loadID 同步转换，保留 burst 状态。

ThinkTree 保存键按原分配时点、父链、短类名、全局碰撞序列和 DeepCopy 的子先父顺序建立旧键别名。随机数使用 Push/Pop 隔离；只有从本次主存档读取的 Job 在 PostLoadInit 使用别名，重存后写规范键。节点的 GetHashCode 会随 uniqueSaveKeyInt 改变，索引必须使用引用相等。

MooGirl 检测和删除收紧到明确类型的位置，不把备注列表或任意字典中的同名文字当成 Def。无时代特征且仅出现于不受支持时代的通用名字不扩成全局删除标记，仍交原版缺失 Def 处理（D3）。旧时代以外的数据不会获得该例外。

## 验证器与读取轨迹

- 消费黄金样例按实际 owner 选择器验证；嵌套对象的同名 age 不能证明外层字段被消费。
- 抽象基类合并后，逐一检查语料中每个具体后代仍保存同一标签、类型、LookMode 和默认值。缺后代或默认值漂移仍失败，不捏造旧基类 Class 对象。
- 增加禁止自身程序集 Harmony 补丁的检查，兼容改走明确扩展点。
- ValidationReadTrace 仅在隔离验证命令行和标记文件同时存在、且测试框架显式启用时工作。记录真实 XML 路径的 Reference、ReferenceList、VerbIdentity、DefReference、ThinkKey 与 DictionaryPairs；无法定位写错误，绝不扫描相同字符串寻找替代节点。正常游戏无轨迹数据和 XML 路径遍历开销。
- 读取轨迹按真实调用顺序应用到独立 DOM 预览，供 A5 精确比较；不把整个 consumed owner 或任意新增字段豁免。
- 缩进 XML 的 Thing 索引跳过格式空白，但不 Trim 玩家文本。

模块缺组引用边界已经完成。本节整合时结构测试合计991项无失败，显式性能测试另行通过，两运行时各45项及strict检查通过。后续最终构建已完成1010项常规测试、1项显式性能测试和完整实机验收，见[完成记录](refactor-1.7-resume-2026-10-15.md#最终验收与交付)。所有语料只读，五个P夹具和AllDlc6存档重复升级零动作。

备份在 DOM 之前完成，失败则不开始升级，已有备份不覆盖；DOM/引用/ThinkTree/必要阶段或安装检查失败均保持失败状态。该流程不声称失败后的内存编辑具有事务回滚能力，恢复依赖原始备份；较新档发出风险提示并保留来源戳，不把它改成当前版本。
