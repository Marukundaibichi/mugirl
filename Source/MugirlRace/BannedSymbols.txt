# BannedSymbols.txt — compile-time guard for the RimWorld 1.7 rule "no Unity compatibility layer".
#
# RimWorld 1.7 runs on the Waylith engine. UnityEngine.* types exist only as UnityStubs, a compatibility layer whose
# behaviour differs from Unity in places (see docs/architecture/ADR-006-unity-boundary.md and the 1.7 migration guide). This build may use the
# UnityEngine types that appear in RimWorld's own API signatures purely as data: construct them, read their fields,
# pass them to the game. Every service and every piece of UnityStubs logic is banned below.
#
# The authoritative check is the post-build IL whitelist in Source/Tests/MugirlRace.Validation; this file reports
# the same problems earlier, in the IDE. Suppress RS0030 only with a comment that states the reason.
